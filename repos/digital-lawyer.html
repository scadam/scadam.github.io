The systems a firm runs on

Document management (DMS), practice management (PMS), a policy & governance store, a risk register, and time & billing — each a file-backed MCP server locally, each a thin REST wrapper (iManage, Clio, ServiceNow GRC, Elite 3E…) in production.

Contract review

Clause-by-clause, with escalation

Runs a 13-step review of a supplier agreement, identifies deviations by severity, and writes a structured escalation pack when — for example — a 3× liability cap exceeds the firm's 1× policy maximum.

Word + Mail

Marks up documents over email

Listens on the email channel, generates a real .docx, inserts tracked changes and comments via the Agent 365 Word MCP Server, and replies with findings via the Mail MCP Server — a fully autonomous 18-step workflow.

Governance

Managed Identity, end to end

Authenticates to every Azure service via Managed Identity — no API keys anywhere. Every tool call is logged with actor identity, inputs, result summary and UTC timestamp in an immutable audit trail.

Activity & Billing dashboard

A Teams-styled tab on Alex's profile — in production it sits alongside Chat, Files and Storyline, giving supervisors an at-a-glance view of the agent's work, billed time and risk decisions.
